### 🔍 `web-vuln-scanner`
> **Ferramenta de varredura de vulnerabilidades web em Python**

Scanner automatizado que identifica endpoints vulneráveis a injeção de SQL, XSS refletido e exposição de diretórios sensíveis. Inspirado nas técnicas do OWASP Top 10, construído do zero para fins educacionais.

- **Vulnerabilidades simuladas:** SQL Injection (GET/POST), Reflected XSS, Directory Traversal
- **Técnica:** Fuzzing de parâmetros com payloads customizados e análise de resposta HTTP

[![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)

### 🐚 `recon-toolkit`
> **Automação de reconhecimento passivo e ativo para Bug Bounty**

Script em Bash que orquestra ferramentas como `subfinder`, `httpx`, `nmap` e `ffuf` para enumerar subdomínios, serviços ativos e diretórios expostos de forma sequencial e com output organizado.

- **Fase coberta:** Reconhecimento (OSINT + ativo)
- **Técnica:** Enumeração de subdomínios, fingerprinting de tecnologias, fuzzing de paths
